# 📖 About

BioForge is a modular bioinformatics toolkit developed in Python for DNA, RNA, Protein, and sequence analysis.

The toolkit provides an intuitive graphical interface along with multiple bioinformatics modules designed for biotechnology students, researchers, and beginners in computational biology.

# ⚙ Installation

Clone the repository

```bash
git clone https://github.com/Suryanshyadav3108/BioForge
```

Move into the project directory

```bash
cd BioForge
```

Install all dependencies

```bash
pip install -r requirements.txt
```

Run BioForge

```bash
python gui/app.py
```
